# 📦 ListIDE — Консольная мини-БД на VB.NET

**ListIDE** — это легковесная консольная база данных, написанная на Visual Basic (.NET Framework). Проект создан как учебный пример реализации файлового хранилища с поддержкой типизации, уникальных ключей и транзакций.

## 🚀 Возможности

* **Три типа данных:** Поддержка `String`, `Integer` и `Binary` (бинарные данные в hex-формате).
* **Надежное хранение:** Данные сохраняются в формате CSV (`list.txt`) с поддержкой экранирования (запятые, кавычки, переносы строк).
* **Уникальные ключи (PRIMARY KEY):** Встроенный индекс `Dictionary` (O(1)) не позволяет создать две записи с одинаковым именем.
* **Транзакции:** Поддержка `BEGIN`, `COMMIT` и `ROLLBACK` для безопасного изменения данных.
* **Атомарная запись:** Сохранение происходит через временный файл (`tmp`), чтобы защитить базу от повреждения при внезапном отключении.
* **LISTA-консоль:** Встроенный командный интерфейс для быстрого управления базой.

## 🛠️ Команды LISTA-консоли

Внутри программы (в пункте меню `7`) доступны следующие команды:

* `NEW STRING <name> <value>` — добавить строку
* `NEW INTEGER <name> <value>` — добавить целое число
* `NEW BINARY <name> <hex>` — добавить бинарные данные (в hex)
* `REMOVE STRING <name>` — удалить запись по ключу
* `OBTAIN DATA` — вывести все записи
* `HELP` — показать справку
* `CLEAR` — очистить экран
* `EXIT` — вернуться в главное меню

## 💻 Требования

* ОС: **Windows 7 / 8 / 10 / 11**
* Среда выполнения: **.NET Framework 4.7.2+** (встроена в Windows 10 и 11 по умолчанию).
* Сборка: Visual Studio 2019/2022 (для запуска из исходников).

## 📥 Как запустить

1. Перейдите в раздел **[Releases](https://github.com/Dmitri433/ListIDE-Mintxa/releases)** (справа на этой странице).
2. Скачайте архив `ListIDE.zip` из последнего релиза.
3. Распакуйте архив в любую папку.
4. Запустите `ListIDE.exe`.

*(Файл `list.txt` с базой данных создастся автоматически рядом с программой при первом сохранении).*

## 🏗️ Структура проекта

* `/Mintxa` — библиотека классов, содержащая ядро базы данных (`Minilist`, `ListElement`, `StrType`).
* `/ListIDE` — консольное приложение (точка входа `Module1.vb`, интерфейс и меню).
